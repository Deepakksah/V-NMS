1. WINDOWS 11 SMART APP CONTROL (SAC) NOTICE & QUICK FIX:
--------------------------------------------------------------------------------
If Windows 11 displays:
"Smart App Control blocked an app that may be unsafe... because we could not verify its publisher"

Choose ANY of the simple solutions below:

OPTION A (Recommended - 1 Click Automatic):
  - Right-click "Install-With-Trusted-Certificate.bat" and select "Run as administrator".
  - This automatically removes the internet download lock (Zone.Identifier),
    registers the Veracity Enterprise Digital Certificate into the Windows Trusted Store,
    and starts the setup with full verified publisher clearance!

OPTION B (Direct Command-Line Unblock via PowerShell):
  - Open PowerShell as Administrator and run:
      Unblock-File -Path ".\V-NMS-Enterprise-Setup-v2.0.0.exe"
      Start-Process ".\V-NMS-Enterprise-Setup-v2.0.0.exe"

OPTION C (Direct MSI Installation):
  - You can install directly via Windows Installer without triggering SAC:
      msiexec /i ".\V-NMS.msi"

OPTION D (Disable Smart App Control in Windows 11 Settings):
  1. Open Windows Settings (Win + I).
  2. Navigate to "Privacy & Security" -> "Windows Security".
  3. Click "App & browser control" -> "Smart App Control settings".
  4. Toggle Smart App Control to "Off".

2. LOCAL NETWORK ACCESS (HTTP WITHOUT SSL):
--------------------------------------------------------------------------------
  Access V-NMS from any client PC, laptop, or phone on the same network:
  
  URL: http://v-nms.com  (or http://<SERVER-IP>)
  Default Username: admin
  Default Password: admin

  To map "http://v-nms.com" on client workstations, right-click and run:
  "Setup-Client-PC-Domain.bat" as Administrator.

3. UNINSTALLATION & CLEAN REMOVAL ("KOI SABOOT NHI"):
--------------------------------------------------------------------------------
  - Re-run "V-NMS-Enterprise-Setup.exe" anytime.
  - The installer will automatically detect an existing installation and prompt:
      [Install]  [Repair]  [Remove]
  - When clicking "Remove", select:
      [X] Total Clean Removal (Removes PostgreSQL DB, credentials, services & temp files)
  - Zero traces left behind.
