--------------------------------------------------------------------------------
1. FRESH INSTALLATION:
--------------------------------------------------------------------------------
1. Right-click 'V-NMS-Enterprise-Setup.exe' -> Select 'Run as administrator'.
2. Review selected components:
   - PostgreSQL 18 Engine
   - V-NMS Core Suite & Poller
   - Database Schema & Tables
   - Official Windows Service ('VNMSService')
   - Windows Firewall Rules (Port 80 & 8081)
3. Click [ ✔ Install V-NMS Now ].
4. The dashboard will automatically launch in your browser.

--------------------------------------------------------------------------------
2. REPAIR / REINSTALLATION:
--------------------------------------------------------------------------------
If V-NMS is already installed on the computer:
1. Run 'V-NMS-Enterprise-Setup.exe' as administrator.
2. Click [ 🔧 Repair V-NMS ].
3. The setup will automatically:
   - Stop and terminate active processes
   - Verify and repair application files
   - Re-register 'VNMSService' with auto-start
   - Re-apply Windows Firewall rules for Port 80 and 8081
   - Verify PostgreSQL connection and tables
   - Start the service and verify health

--------------------------------------------------------------------------------
3. INTERACTIVE REMOVAL / ZERO-TRACE CLEAN WIPEOUT:
--------------------------------------------------------------------------------
If you want to uninstall V-NMS:
1. Run 'V-NMS-Enterprise-Setup.exe' as administrator.
2. Click [ 🗑️ Remove / Uninstall ].
3. Select what to remove via interactive checkboxes:
   [x] V-NMS Application & Binaries (C:\Program Files\V-NMS, Shortcuts)
   [x] Windows Service ('VNMSService' stopped & deleted)
   [x] Windows Firewall Rules (Ports 80 & 8081 deleted)
   [x] 'vnms' Database Data & Tables (Dropped from PostgreSQL)
   [ ] PostgreSQL 18 Server & Engine (Optional: tick for full engine wipeout)
   [x] Temporary Files & Payload Cache (%TEMP% staging wiped)
   [x] Local Domain (v-nms.com) from Hosts & Registry Keys

   * OR TICK: [x] TOTAL CLEAN WIPE (KOI SABOOT NAHI)
     Permanently erases 100% of files, PostgreSQL, services, temp files, 
     firewall rules, and registry keys with ZERO residual bytes left on the PC!

4. Click [ 🗑️ Confirm & Execute Clean Removal ].
